# 후보 비교·선정과 호출 비용 재검증

2026-10-15 v2 경로의 검증 기록이다. 이후 생성 계약과 비용 변경은 [비용 절감 결과](cost-optimization-results.md)에 기록했다. 기본 요청은 모델 최대 1회이며, 제공된 합성 데이터와 실제 OpenRouter `openai/gpt-5.4`를 사용했다. 실제 고객 제품 기능이나 `.example` 사이트 본문을 검증한 것은 아니다.

## 무엇을 바꿨나

- 같은 질문을 푸는 서로 다른 개입 방식 3개를 비교한다. 근거·효과 가설·노력과 가정·실행 조건·위험·선정/보류/배제 이유·선정 변경 조건을 반환한다.
- 보조 출처와 편집 후보를 별도 역할로 분리한다. 전체 후보에 같은 필수 조건을 적용한 뒤 선택하는 절차를 코드로 구성한다.
- 공개 placeholder·미확인 주장은 해소하거나 삭제하고, 필수 정보가 없으면 게시를 보류한다. 후속 수집은 게시 URL과 자사 출처 ID, 게시 시각이 모두 확정돼야 한다.
- 주요 질문의 언급·추천·인용 수치는 코드로 렌더링한다. 주요 성과는 언급·추천이고 인용은 보조 지표이므로 인용만 늘면 성공으로 보지 않는다. 내부 검증 작업에는 게시 후 측정을 적용하지 않는다.
- 선정 후보의 선행 조건을 실행안에 코드로 이관한다. 모델의 원래 조건도 보존하며, 서로 다른 표현을 임의로 동의어라고 판정하거나 삭제하지 않는다.

## 품질 판정 기준

결과를 보기 전에 고정한 5개 축을 각각 0~2점으로 검토한다: 근거·문제 적합성, 같은 문제의 후보 비교·선정, 실행 가능성, 사실·자산·게시 일관성, 측정. 합계 8/10 이상, 모든 축 1점 이상, 새 P1/P2 없음, 기존 필수 회귀 조건 충족이 모두 필요하다. 독립 Codex 읽기 전용 내용 검토이며 사람 평가나 실제 효과 실험이 아니다. 별도 유료 모델 평가 호출을 추가하지 않는다.

## 비용 관측 검증

Langfuse는 별도 Docker 프로젝트에 설치했다. 프로젝트 전체 합계를 실험 비용으로 사용하지 않고, 각 결과의 `validation_receipt`에 기록된 실제 invocation만 조회한다. 실패 호출도 포함한다.

호출 1건마다 GENERATION 1개인지, 입력·출력·캐시·추론 토큰이 중복 집계되지 않는지, 실제 `usage.cost`와 `costDetails.total`·trace 총액이 일치하는지 확인한다. 상태·지연·모델·주제·질문·정책도 대조한다. 공급사 생성 성공과 제품 검증 성공은 별도다. 예를 들어 생성이 완료돼도 제품 검증이 실패하면 최종 결과는 fallback이다.

최종 조회 대사에서 10/10건이 통과했고, 공급사 영수증과 해당 trace 비용 합계는 모두 **$1.803157**로 일치했다.

검증 스크립트는 [verify_langfuse.py](../scripts/verify_langfuse.py), 결과는 [호출별 대사](../output/product-v2-langfuse.json)다. 전송이 받아들여졌다는 응답만으로 비용 저장 성공을 주장하지 않고 조회 API에서 대조한다.

실제 비용이 없는 응답은 미확인으로 남긴다. 과제의 M 호출 단가 $0.018과 Langfuse 자체 추정 가격을 실제 청구액으로 바꾸지 않는다. Langfuse의 서버 비용은 아직 월간 실측하지 않았으므로 기존 $6 인프라 가정이나 과제 마진을 실제 원가 달성으로 주장하지 않는다.

## 재현

```sh
python3 scripts/setup_langfuse.py
docker compose -f compose.langfuse.yaml up -d --wait --wait-timeout 300
uv run python scripts/validate_product_v2.py --output-dir output/my-new-run
# 동일 고객·입력·정책이라면 캐시 재사용. 원장과 기존 출력은 지우지 않는다.
uv run python scripts/verify_langfuse.py output/my-new-run/lead.json \
  output/my-new-run/unsupported.json output/my-new-run/security.json
```

검증용 출력 폴더가 이미 있으면 실행 스크립트는 덮어쓰지 않고 종료한다. Langfuse 대사에는 실제 호출의 영수증이 있는 결과만 전달한다. 호출 0회인 캐시 재실행 결과에는 새 generation이 없다.
