# 호출 비용 절감 결과

2026-10-15 기준. 운영 설정은 **OpenRouter GPT-5.4, reasoning=low, 최대 1회 호출**이다. 모델에 보내는 근거와 생성 계약을 줄여 기존 네 사례의 평균 비용을 **$0.185761875 → $0.102391875**, **44.88%** 낮췄다. 네 사례 모두 기존 내용 평가 이상을 받았다.

## 적용한 변경

- 모델은 액션 후보 3개, 비교·선정 근거, 자산의 관련성, 작업 초안과 완료 조건을 생성한다. 후보와 액션의 중복 필드, 코드가 다시 작성하는 측정·게시 설명은 생성에서 제외했다.
- 근거 ID 선택지는 스키마에 한 번만 정의한다. 관계 정보의 중복, 반복 지표 설명, 상위 관측 ID 반복을 제거했다.
- 반복 레코드는 열 이름과 행 배열로 전달한다. 다른 질문의 반례, 전체 출처 목록, 제품 사실, false/unknown 상태를 유지한다. 복원 결과가 압축 전 입력과 같은지 검사한다.
- 추론 수준을 medium에서 low로 변경했다. 출력 상한은 16,000을 유지했다. 사용하지 않은 출력 한도를 절감액으로 계산하지 않는다.
- 실제 USD 원장을 추가했다. 호출 전 비용을 예약하고 영수증으로 정산하며, 실패 비용도 포함한다. 미확인 비용은 0으로 처리하지 않는다.

원본 지표 집계와 실행 계약 검증은 압축 전 근거로 수행한다. 문자열을 줄이려고 제품 사실이나 후보 비교를 삭제하지 않았다. 표 전달 방식만의 추가 문자량 감소는 23.34%이며, 이는 토큰 절감률과 다르다. [입력 복원 검사](compact-input-audit.json).

## 실제 호출 비교

각 설정을 lead·unsupported·security·confirmed 네 사례에서 독립적으로 호출했다. 요청 안에서 모델 교체, 재시도, 재작성은 하지 않았다.

| 설정 | 입력 형태 | 평균 실제 비용 | 채택 |
| --- | --- | ---: | --- |
| 기존 GPT-5.4 medium | 전체 계획 생성 | $0.185761875 | 비교 기준 |
| mini low | 축소 계약 | $0.0269176875 | 제외: 미확인 대체 경로·게시 조건 오류 |
| mini none | 축소 계약 | $0.0236484375 | 제외: 미지원 사실을 다시 미확인으로 취급 |
| mini medium | 축소 계약·표 입력 | $0.0503206875 | 제외: 자산 검사 우회·필수 필드 가정 |
| GPT-5.4 none | 축소 계약·표 입력 | $0.082363125 | 제외: 미확인 수동 등록 경로를 가능하다고 안내 |
| **GPT-5.4 low** | **축소 계약·표 입력** | **$0.102391875** | **적용** |

새 실험 20회 총비용은 **$1.14256725**다. 품질 검토에서 탈락한 호출도 포함한다. 20회 모두 구조 검사는 통과했지만, 구조 통과를 추천 품질 통과로 세지 않았다. [전체 비용 계산](../output/cost-optimization-costs.json), [Langfuse 20/20 대사](../output/cost-optimization-langfuse.json).

채택한 설정의 사례별 결과는 다음과 같다. 점수는 근거·후보 비교·실행 가능성·제품 사실과 자산/게시 조건·측정의 다섯 축, 총 10점이다. 독립 Codex 내용 검토이며 사람의 최종 승인이나 실제 사업 효과 평가가 아니다.

| 사례 | 기존 점수 | 변경 후 점수 | 변경 후 비용 | 선정한 작업 |
| --- | ---: | ---: | ---: | --- |
| lead | 9 | 9 | $0.0984475 | 내부 경로·자산 검증 |
| unsupported | 9 | 10 | $0.0953350 | 미지원 사실에 맞는 안내·내부 절차 확인 |
| security | 10 | 10 | $0.0936050 | 기존 보안 자산 검사 후 개정 |
| confirmed | 9 | 9 | $0.1221800 | 확인된 연동 경로의 실행 검증 |

P1/P2는 없었다. lead 내부 표의 자산·기준 표기를 통일하고, confirmed의 필수값 예시를 운영자 확인 항목으로 정리할 편집점(P3)이 남았다. 세 작업은 내부 검증이므로 네 건 모두 즉시 게시할 문서가 완성됐다고 해석하면 안 된다. 실제 제품 연동·게시·성과 측정은 수행하지 않았다. [채택 설정 내용 검토](../output/cost-table-gpt54-low/quality-audit.json).

## 토큰과 비교 범위

| 네 사례 합계 | 기존 | 변경 후 |
| --- | ---: | ---: |
| 입력 토큰 | 95,589 | 52,185 |
| 입력 중 공급사 캐시 | 48,640 | 0 |
| 출력 토큰, 추론 포함 | 40,901 | 18,607 |
| 출력 중 추론 | 24,350 | 5,261 |
| 실제 비용 | $0.7430475 | $0.4095675 |

기존 표본은 공급사 입력 캐시 할인을 받았고, 새 표본은 모두 캐시 미적중이었다. 44.88%는 이 영수증끼리의 비용 감소다. 입력·출력·추론 변경 각각의 인과 효과나 장기 운영 평균으로 일반화하지 않는다. 공급사 입력 캐시는 출력 비용을 없애지 않으며, 앱의 결과 캐시는 모델 호출 자체를 생략한다.

## 마진 조건

구독 $100, 월 추천 1,000회, 인프라 $6과 수집비 $3.87을 가정하면, 변경 후 단가로 모두 새 생성할 때 원가는 **$112.26**, 마진은 **-12.26%**다. 비용을 낮췄지만 마진 80% 조건을 충족한 것은 아니다.

| 월 조건 | 모델에 쓸 수 있는 비용 | 새 생성 상한 | 나머지에 필요한 유효한 0회 처리 |
| --- | ---: | ---: | ---: |
| 평균 4.3주 수집 | $10.13 | 98회 | 902건, 90.2% |
| 5회 수집 | $9.50 | 92회 | 908건, 90.8% |

표는 관측 평균 단가가 유지되고 Langfuse 증분 배부 비용이 0인 민감도 계산이다. 실제 요청 분포·캐시 적중률·관측 인프라 월비용은 검증하지 않았다. 5주 수집월의 증분 비용이 `h`이면 새 생성 상한은 `floor((9.50-h)/0.102391875)`다. 예산 초과로 추천을 못 하는 fallback을 유효한 재사용으로 세지 않는다.

과제의 M 고정 단가 **$0.018/회는 바꾸지 않았다.** 이 계산에서는 여전히 1,000회 새 생성의 마진이 72.13%이며, 평균월 562회 이하의 유료 호출이 필요하다. 공급사 요금 절감과 과제 단가 계산은 별개다.

- 테스트 473개와 하위 테스트 18개 통과.
