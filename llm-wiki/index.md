# 코드 읽기 안내

VIVI는 AI 검색 관측 데이터를 실행 초안으로 연결한다. 기본 흐름은 로컬 근거 수집, 과업 선정, 모델 최대 1회 호출, 계약 검사, 사용자 검토·저장이다. 업무 판단은 LangGraph에 있고 API와 화면은 입력·표시·저장을 맡는다.

기계용 진입점은 [index.yaml](index.yaml)이다. 각 색인의 `path`는 저장소 루트 기준이며, `repository_root`는 해당 색인 파일에서 저장소 루트까지의 상대 경로다. 위키에는 코드 역할과 변경 영향을 적는다. 원본 데이터·프롬프트·실행 결과를 복제하지 않는다.

| 읽을 내용 | 문서 | 먼저 볼 코드 |
| --- | --- | --- |
| 요청 분기와 추천 계약 | [에이전트](agent/guide.md) | [product.py](../src/vivi_agent/product.py) |
| 정제, 집계, 관계, 사용자 상태 | [데이터](data/guide.md) | [evidence.py](../src/vivi_agent/evidence.py) |
| 로컬 실행, Docker, 비용, 관측 | [실행](runtime/guide.md) | [compose.yaml](../compose.yaml) |
| 테스트와 품질 평가 | [검증](validation/guide.md) | [tests](../tests) |

처음 읽을 때는 에이전트 → 데이터 → 실행 → 검증 순서로 본다. 변경할 때는 관련 모듈의 테스트와 위키의 변경 영향 표부터 확인한다.

검증한 운영 설정은 OpenRouter의 `openai/gpt-5.4`, `reasoning_effort=low`, 출력 상한 16000이다. 입력 근거는 표 형식으로 압축하고 모델은 같은 질문의 후보 3개와 선택한 작업의 구체 초안을 만든다. 게시·측정의 반복 규칙은 코드가 붙인다. 설정값의 출처는 [.env.example](../.env.example)이며 키 값은 로컬 환경에만 둔다.

제공 데이터는 합성 데이터다. 구조 검사 통과는 제품 기능의 진실성이나 실제 개선 효과를 보장하지 않는다. 현재 결과는 사람의 확인이 필요한 초안이며 자동 게시·제품 연동 실행·후속 노출 상승을 검증한 결과가 아니다.
