중단·수정 조건: 각 회차에서 고정 페어가 빠진 지표는 효과 결론을 내리지 말고 해당 질문/채널을 추가 수집합니다. partial·failed·언어 불일치를 0 노출로 간주하거나 더 작은 분모로 성공률을 비교하지 않습니다. 보조 지표의 결측은 해당 보조 지표의 판정을 보류하며, 주요 지표의 결과를 대체하지 않습니다. 게시 후 14일 시점의 주요 지표가 모두 완전한 고정 표본인데도 하나도 개선되지 않았거나 악화되면 선택한 자산·제목·서두·FAQ 및 개입 가설을 재검토합니다. 표본이 불완전하면 실패나 무효과를 선언하지 않고 추가 수집이 우선입니다. 자산 선택·등록 상태는 pending_asset_selection_or_registration입니다(후보: SRC001, SRC003, SRC022). 게시 전에 최종 자산의 정확한 URL과 자사 소유 source ID 등록을 완료하고, 기존 자산 개정이면 실제 선택한 source ID를 확정합니다. 후보 목록이나 등록 요청만으로 완료 처리하지 않으며, 이 조건이 해결될 때까지 후속 수집을 보류합니다.

- 검증된 제품 사실이 제공되지 않아, 현재 AI 응답 속 기능 언급을 OrbitCRM의 확정 capability로 볼 수 없다.
- 소스 본문 접근이 없어 SRC001·SRC003·SRC022가 실제로 Q068를 직접 다루는지는 아직 확인 전이다.
- 현재 결론은 리드 관리 주제의 15개 응답 범위에 한정되며, 관측 변화는 인과가 아니라 서술적 비교다.
- 게시 전까지는 준비 작업은 가능하지만, 제품 사실 확인 전에는 기능 단정 문구로 발행하면 안 된다.
